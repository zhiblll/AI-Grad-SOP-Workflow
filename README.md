# AI-Grad-SOP-Workflow
An AI-assisted workflow for writing and customizing SOPs for graduate programs.
一个用于美国研究生申请的 AI 辅助 SOP 工作流。

这个项目整理了我在研究生申请过程中实际使用的LLM写作方法：不是让LLM直接生成文书，而是先分析申请者的简历、成绩单、科研经历和个人叙述，通过多轮对话挖掘值得写入 SOP 的内容，再生成初稿并进行学校定制。

## 项目内容

- `prompts/`：适用于 ChatGPT、Claude、Gemini 等普通 LLM 的 Prompt 版本
- `skills/`：适用于 Codex、Claude Code 等 Agent 环境的 Skill 版本

目前主要包含：

- SOP 第一版开发：材料分析、经历挖掘、多轮访谈、叙事构建

## 核心理念

这个工作流最核心的原则是：

> **先理解申请者，再开始写作。**

LLM 收到简历、成绩单、论文、项目经历和个人叙述之后，第一步不是生成文书，而是先从招生官视角分析材料，寻找：

- 哪些经历真正有区分度
- 哪些故事值得写进 SOP
- 哪些地方只是简历复述
- 哪些研究动机还不够清楚
- 哪些经历之间缺少逻辑连接
- 哪些关键信息还需要继续追问

随后，LLM 会像一次真实的申请咨询一样进行多轮对话。

如果用户的回答仍然过于模糊，例如：

> “这个项目让我对 AI 更感兴趣。”

工作流不会直接接受这个答案，而会继续追问：

> 具体是哪一个问题、实验结果或失败让你的兴趣发生了变化？  
> 你本人做了什么？  
> 你从中学到了什么？  
> 这段经历为什么会影响你之后的研究方向？

只有当申请者的核心经历、研究兴趣、未来目标和项目匹配关系已经足够清楚之后，AI 才会进入正式写作阶段。
最终目标不是让 AI 代写一篇看起来很厉害的文书，而是通过协作，把申请者真实经历中最值得表达的部分挖掘出来，并组织成一条自然、具体、有说服力的学术发展轨迹。

## 使用方式

可以直接复制 `prompts/` 中的 Markdown 内容到常用 LLM 中使用。
或者使用支持 Skill 的 Agent，可以将 `skills/` 中对应的 Skill 安装到 Agent 环境中。

开始第一版 SOP 开发时，建议同时提供：

- 目标学校 / 项目名称
- CV / Resume
- 成绩单（Transcript）
- 科研、论文、项目、实习等经历材料
- 简单的个人经历、研究兴趣和未来目标的补充描述
- 目标项目官方 SOP Prompt、Word Limit 和项目介绍（可选）

材料不需要一次整理得非常完美，也可以先上传已有文件，再通过后续多轮对话逐步补充。

工作流不会在收到材料后立即生成 SOP，而是先分析申请者背景并提出针对性问题，持续补充关键信息，直到经历、研究兴趣、未来目标和项目匹配关系足够清晰后，再进入第一版文书撰写。
